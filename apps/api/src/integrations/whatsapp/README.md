# whatsapp

Notificações ao streamer (RF-OPE-08). Fornecedor em `WHATSAPP_PROVIDER`:

- `evolution`: Evolution API self-hosted, número ligado por QR code (como no UOR Connect). Arranque em `infra/evolution/README.md`.
- `meta`: WhatsApp Cloud API oficial (`WHATSAPP_TOKEN`, `WHATSAPP_PHONE_ID`).
- `console`: só log.
